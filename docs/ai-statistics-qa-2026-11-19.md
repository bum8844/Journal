## 1. AI 한마디 추가 수정

대상: `Journal/AI/ReflectionCommentGenerator.swift`.

### 문제와 원인

실제 응답이 **“다음 주 학습을 준비하면서 다음 행동을 추천해 드립니다.”**에서 끝났습니다. 기존 검사는 ‘추천’이라는 단어만 있어도 제안으로 받아들이고, 해당 표현이 없으면 첫 문장을 대신 선택하여 구체적인 행동이 없는 문장이 표시될 수 있었습니다.

### 로컬 수정 내용

- 프롬프트에서 무엇을 어떻게 할지 작은 행동 하나를 한국어 존댓말 한 문장으로 요청합니다.
- 소개·평가·회고 요약 대신 실제 행동을 제안하도록 안내합니다.
- ‘추천’ 단어만으로 채택하거나 첫 문장을 대신 표시하던 처리를 제거했습니다.
- ‘보세요/어떨까요’ 권유 문장을 선택하되, 확인된 소개 문장·자기 계획 문장은 제외합니다.
- 제안을 얻지 못하면 **“구체적인 행동 제안을 만들지 못했어요. 다시 생성해 주세요. 회고는 그대로 저장할 수 있어요.”**라고 안내합니다.
- 기존 모델 준비 오류의 1회 재시도 및 응답 제한 구분은 유지합니다. 안전 필터를 우회하지 않습니다.

모델·DB 필드·작성폼 연결 인터페이스 변경은 없습니다. 기존 생성·저장 연결을 사용합니다.

## 2. 통계 추가 수정과 현재 범위

대상: `ReflectionStatistics.swift`, `ReflectionStatisticsView.swift`, `ReflectionStatisticsCharts.swift`.

미래 시작 기간을 ‘진행 중’으로 세던 문제를 수정했습니다. 시작일을 집계 입력에 추가하고 **예정 / 진행 중 / 종료 / 종료일 없음**으로 나눕니다.

| 상태 | 기준 |
|---|---|
| 예정 | 시작일 전 |
| 진행 중 | 시작일부터 종료일 당일까지 |
| 종료 | 종료일 다음 날부터 |
| 종료일 없음 | 종료일이 비어 있음 |

시작일이 없는 기존 글은 작성일로 대체합니다. 선택 주·월의 집계 대상은 기존 합의대로 `createdAt` 기준입니다.

현재 로컬 통계 범위는 작성 주/월·날짜별 건수·하루/기간·사진·일정 상태·중요도·태그·카테고리입니다. **오늘의 경험(4L) / 내일을 위한 정리 / 자유 형식별 건수는 추가하지 않았습니다.**
