## 수정 내용

| 항목 | 바뀐 동작 |
| --- | --- |
| 분류없음 | 새 회고에서 카테고리를 비우면 `분류없음`으로 저장합니다. 기존 빈 값·공백·`미분류`도 목록·상세·필터·통계에서 분류없음 하나로 취급합니다. |
| 검색 결과 없음 | 기존 빈 화면 스타일의 책 아이콘과 중앙 안내를 사용합니다. `기록을 찾을 수 없어요 / 다른 검색어를 입력하세요.`를 표시합니다. |
| 필터 결과 없음 | 검색어 없이 필터만으로 0건이면 `필터를 바꾸거나 해제해 보세요.`라고 안내합니다. 검색창·필터 터치는 안내가 막지 않습니다. |
| 날짜 일치 | 하루 회고 상세도 선택한 날짜를 표시합니다. 날짜가 없는 기존 글은 작성일로 대체하고, 기간은 시작일~종료일 표시를 유지합니다. |
| 태그 없음 | 태그 없는 글만 조회하는 칩을 추가했습니다. 결과의 글을 눌러 상세로 이동할 수 있습니다. |

`태그 없음`은 실제 태그로 저장하지 않습니다. 개별 태그 선택과 상호 배타적이며 카테고리·검색어는 함께 적용됩니다. `필터 해제`는 카테고리·개별 태그·태그 없음 조건을 모두 초기화합니다.

글의 작성일과 선택 날짜는 별개입니다. 작성일 기준 정렬·통계는 기존 합의대로 유지합니다. DB 필드·스키마·프로젝트 설정 변경은 없습니다.
