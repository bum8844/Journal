# AI 한마디 팀 공유

- **동작 방식** — 작성·편집 화면에서 **AI 한마디 생성**을 누르면 Apple Intelligence의 기기 내 모델이 회고 내용을 바탕으로 다음에 시도할 행동을 한국어로 제안합니다. 외부 API나 API 키는 사용하지 않습니다. 회고를 저장하면 상세 화면 하단에 표시됩니다.
- **사용 조건** — Apple Intelligence를 지원하는 기기에서 기능이 켜져 있고, 모델이 준비되어 있으며 한국어 생성을 지원해야 합니다. 생성 기능을 사용할 수 없는 상태에서도 회고 작성과 저장은 가능합니다.
- **시뮬레이터 검증** — iPhone 18 Pro(iOS 27.2)에서 자유·오늘의 경험·내일을 위한 정리 모두 실제로 문장을 생성했습니다. 저장 후 상세 화면에 각 문장이 그대로 표시되는 것을 확인했습니다.
- **팀 브랜치** — [upstream/work/yeongyu](https://github.com/bum8844/Journal/tree/work/yeongyu)

## 2026-11-18 범용 프롬프트 검증

- 긴 복합 지시문과 수영·영단어 회고 조합에서 응답 제한 오류를 재현했다. 같은 입력과 지시문으로 Mac과 iOS 시뮬레이터에서 동일하게 발생했다.
- 짧은 범용 지시문으로 변경하고 응답 선택 방식은 greedy로 설정했다. 안전 필터는 기본 설정을 유지한다. 필터 내부 판정 이유는 API가 공개하지 않아 특정 단어가 원인이라고 확정할 수 없다.
- 수정본은 시뮬레이터에서 산책·수영·영단어·짧은 일상 기록을 각각 두 번 생성하고 저장해 8회 통과했다. Mac에서도 수영·영단어를 두 번씩 생성해 4회 통과했다.
- 최종 생성 검사는 검증용 복사본에서 동일 생성 함수와 SwiftData 저장을 실행했다. Device Hub 입력이 응답하지 않아 최종본의 직접 버튼 조작 재검증은 완료하지 못했다.
- 모델이 응답을 제한하면 제한 안내를 표시하고 기존 회고와 AI 문장을 보존한다. 이 검증은 사용한 입력 사례의 결과이며 다른 입력에서도 같은 응답을 보장하지 않는다.

## 2026-11-19 모델 준비 오류 대응

- 현재 생성은 역할을 구분하는 짧은 지시문과 모델의 기본 생성 방식을 사용한다. 위 11/18의 greedy 검증은 당시 이력이다.
- 부팅 직후 관찰한 `OnDeviceInferenceAssetRepository` 도메인, 코드 2가 중첩 오류에 있거나 모델이 `modelNotReady`이면 준비 실패로 구분한다. 모든 필터 오류를 준비 실패로 간주하지 않는다.
- 준비 실패만 2초 후 새 세션으로 한 번 재시도한다. 다시 실패하면 종료하며, 대기 중 화면을 나가 취소하면 후속 요청을 보내지 않는다.
- `guardrailViolation`·`refusal`은 응답 제한으로 안내하며 자동 재시도하지 않는다. 그 밖의 알 수 없는 오류도 자동 재시도하지 않는다.
- 준비 실패와 응답 제한 모두 AI 없이 회고를 저장할 수 있다. 지원하지 않는 기기·Apple Intelligence 꺼짐 등 기존 사용 조건은 유지한다.

## 일정·중요도 통계

- 선택한 주·월에 작성된 회고를 기준으로 기간 회고의 진행 중·종료·종료일 없음과 중요도 1·2·3단계 건수를 표시한다.
- 종료일 당일은 진행 중이며 다음 날부터 종료로 집계한다. 중요도가 없는 기존 글은 2단계다.
- 종료일 경계, 종료일 누락, 기간 밖 회고 제외, 중요도 합계, 빈 기간의 집계 검사를 통과했다.
